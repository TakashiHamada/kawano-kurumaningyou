# 川野車人形 練習用音声プレーヤー

川野車人形（かわのくるまにんぎょう）の語りを練習するための、Web ベースの音声プレーヤーアプリケーションです。

## 川野車人形とは

川野車人形は、日本の伝統的な人形芝居の一つです。本アプリでは、熟練の演者による貴重な録音を聴きながら語りの練習を行うことができます。

## 使い方

1. Web サーバー（GitHub Pages など）に置いた `index.html` をブラウザで開きます
   ※ `index.html` をファイルとして直接開く（ダブルクリック）と、音声一覧を
   読み込めません。手元で確認するときは、このフォルダで `npx serve` などの
   Web サーバーを起動してください
2. ドロップダウンメニューから聴きたい音声を選択します
3. 「再生」ボタンで再生、「5秒戻す」ボタンで巻き戻しができます
4. 一部分を繰り返し聞きたいときは、「ここから」「ここまで」で区間を設定します

## 主な機能

- 音声の再生・一時停止
- 5秒巻き戻し
- 区間リピート（「ここから」「ここまで」で区間を指定。「解除」で全体ループに戻る）
- 再生速度の切り替え（0.6x / 0.8x / 1.0x）
- 演目・話者・収録日の表示
- 関連画像（台本など）の閲覧 ※画像が登録されている音声のみ
- スマートフォン対応（縦向き表示）

## 区間リピートについて

- 「ここから」を押した位置が開始点、「ここまで」を押した位置が終了点になります
  （「ここまで」だけを押した場合は、音声の先頭が開始点になります）
- 再生が終了点に達すると、開始点に戻って繰り返し再生します
- 区間を設定したままでも、再生スライダーで区間の外へ自由に移動できます。
  区間より後ろへ移動した場合は、音声の最後まで再生したあと開始点に戻ります
- 音声を切り替えると、区間と再生速度は解除されます

## 関連画像（台本）の表示について

音声を選ぶと、音声情報（audio-info）の右下に画像アイコン（🖼）が表示
されます。関連画像がある音声ではアイコンがアクティブ（押せる状態）になり、
ない音声では非アクティブ（押せない状態）になります。

アイコンを押すと音声情報のすぐ下に関連画像が表示され、アイコンは「×」に
変わります。「×」を押すと画像が閉じます。画像をタップすると拡大・縮小できます。

画像は CSV に登録する必要はありません。**`img/` フォルダに、音声ファイルと
同じ名前（拡張子だけ違う）の画像を置くと、自動的にその音声と関連づけられます。**
1 つの音声につき、同名で拡張子が `.jpg` / `.jpeg` / `.png` の画像を探します。

| CSV の filename | `img/` に置く画像（例） |
|-----------------|-------------------------|
| `practice_sugita_0.mp3` | `practice_sugita_0.jpg` |
| `practice_sugita_1.mp3` | `practice_sugita_1.jpg` |

## 新しい音声ファイルの追加方法

1. MP3 形式の音声ファイルを `audio/` フォルダに配置します
2. `audio_metadata.csv` をテキストエディタで開き、末尾に新しい行を追加します

```
ファイル名,演目名,話者名,収録年月日
```

**例:**

```csv
filename,title,speaker,recorded_date
kowakare_furuya.mp3,子別れ,古谷要平,昭和51年7月11日
watashiba_sugita.mp3,保存版「渡し場」三味線なし,杉田芳春,平成8年頃
togo-kowakare_haruji.mp3,当吾 子別れ,島崎春治,平成23年3月
newfile.mp3,新しい演目,演者名,令和○年○月   ← この行を追加
```

3. 台本などの画像を表示したい場合は、その音声と同じ名前の画像を `img/`
   フォルダに置きます（例: `newfile.mp3` → `img/newfile.jpg`）

**注意事項:**

- 音声ファイルは MP3 形式のみ対応しています
- CSV の各項目はカンマ（`,`）で区切ってください。演目名などの中にカンマは
  使えません（カンマの前後の空白は自動的に取り除かれます）
- 関連画像は `img/` フォルダに、音声ファイルと同じ名前（拡張子のみ `.jpg` /
  `.jpeg` / `.png`）で配置してください
- ファイル名に日本語やスペースは使わず、半角英数字とハイフン・アンダースコアを推奨します
